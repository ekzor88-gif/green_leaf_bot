# Green Leaf Bot 🌿

Telegram-помощник на базе ИИ для каталога органической продукции Green Leaf.

## Обзор
Этот бот предоставляет интерфейс на естественном языке для поиска и получения информации о товарах из каталога Green Leaf. Он использует технологию RAG (Retrieval-Augmented Generation) для предоставления точных ответов на основе данных из каталога.

## Технологический стек
- **Фреймворк для бота**: [aiogram 3](https://docs.aiogram.dev/)
- **Модели ИИ**: 
  - `gpt-4o-mini` для чата и классификации запросов.
  - `text-embedding-3-small` для семантического поиска.
- **База данных**: [Supabase](https://supabase.com/) (PostgreSQL с расширением `pgvector`).
- **Хранилище данных**: Supabase Storage для изображений товаров.
- **Среда выполнения**: Python 3.10+

## Основные возможности
- **Гибридный поиск**: Сочетает точное совпадение строк, поиск по ключевым словам и векторный семантический поиск.
- **Контекстный диалог**: Бот понимает уточняющие вопросы (например, "какой состав?" или "как применять?") без нового поиска по каталогу, извлекая данные из контекста с помощью LLM на лету. Длинные ответы автоматически разбиваются для обхода ограничений Telegram.
- **Реализация RAG**: Использует фрагменты описаний товаров для предоставления контекста нейросети.
- **Динамическая связь с менеджером**: Генерирует ссылки на WhatsApp, которые могут вести к конкретным партнерам на основе реферальных кодов.
- **Автоматическая загрузка данных**: Скрипт `update_catalog.py` парсит документ Word (`catalog.docx`), загружает изображения и генерирует поисковые теги и эмбеддинги.
- **Реферальная система**: Поддерживает "глубокие ссылки" (deep linking) с кодами партнеров.

## Структура проекта
- `bot.py`: Основная точка входа и логика обработки Telegram-событий.
- `llm.py`: Взаимодействие с OpenAI API (генерация ответов, классификация).
- `db.py`: Операции с базой данных (Supabase) и логика поиска.
- `embeddings.py`: Утилиты для генерации векторных представлений и поисковых тегов.
- `update_catalog.py`: Скрипт для импорта данных из `catalog.docx`.
- `schema.sql`: Определение схемы базы данных.

## Настройка
1.  **Переменные окружения**: Создайте файл `.env`:
    ```env
    TELEGRAM_TOKEN=ваш_токен_бота
    SUPABASE_URL=ваш_url_supabase
    SUPABASE_KEY=ваш_ключ_supabase
    OPENAI_API_KEY=ваш_ключ_openai
    ```
2.  **База данных**: Выполните SQL-запрос из `schema.sql` в редакторе Supabase.
3.  **Установка зависимостей**:
    ```bash
    pip install -r requirements.txt
    ```
4.  **Загрузка данных**:
    ```bash
    python update_catalog.py
    ```
5.  **Запуск бота**:
    ```bash
    python bot.py
    ```
